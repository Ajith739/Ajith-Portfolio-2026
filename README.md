# 🛠️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/portfolio.git
```

## Navigate To Project

```bash
cd portfolio
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```
